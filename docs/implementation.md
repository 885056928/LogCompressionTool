## 日期压缩扩展（2026-10-13）

- 日期识别限定根目录直接子文件夹，兼容单数字月日，按 DateOnly 排序。
- 按天压缩复用 CompressAsync；多天使用 CompressDaysAsync 直接将每日 ZIP 写入总 ZIP，外层不重复压缩。
- 共享日志写入与目标提交检查；目标状态在扫描前记录，并反馈真实扫描阶段。
- LogFile 增加可选 InnerArchiveName，实现总包内日志的列表、读取与修改保存；压缩包临时缓存自动删除。
- 日期选项采用独立 DaySelectionViewModel，压缩交互收于 MainViewModel.Compression.cs；保留 MVVM 属性/命令/方法分类。
- 日期 Popup 替代展开列表，避免挤占 1000×650 窗口内容；批次取消/错误保留已完成日期，已有目标统一确认覆盖。
- 验证：VerifyDays 10/10、原有 Verify 15/15 通过；WPF 增量运行验证通过，绑定警告/错误 0，含 Escape 关闭与焦点恢复。40 个示例日志普通 ZIP 与 10 个每日 ZIP 合成总包的 SHA-256 均一致，总包 100,266,900 字节，可直接读取预览。最终 Release 编译 0 警告/错误。项目和临时目录无遗留压缩缓存文件。
